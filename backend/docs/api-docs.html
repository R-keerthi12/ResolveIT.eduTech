ResolveIt
API Docs

Complete reference for the ResolveIt Grievance Portal backend — a Node.js / Express REST API with JSON file persistence, role-based access control, and full CRUD for grievances, users, and feedback.

Base URL: http://localhost:3000/api
Node ≥ 16
Express 4
No DB required
Overview
Base URL, setup, and quick start

⚡ Quick Start

Terminal
# 1. Enter the backend folder cd resolveit_v2/backend # 2. Install dependencies npm install # 3a. Run in production mode npm start # 3b. Run with auto-reload (development) npm run dev # Server starts at http://localhost:3000 # Frontend is served at the same origin — no extra web server needed.

🌐 Base URL

http://localhost:3000/api
ℹ️
All responses are JSON. Send Content-Type: application/json on POST / PATCH requests. Data is stored in backend/data/*.json files, which are auto-created and seeded on first run.
Authentication
Token-based via HTTP Authorization header
⚠️
Tokens are base64-encoded email:role strings for demo simplicity. Replace with JWT before going to production.

🔑 How It Works

1. Call POST /api/auth/login with your email and password.
2. Receive a token string.
3. Send it on every subsequent request:

Request Header
Authorization: Bearer <token>

🎭 Roles & Permissions

RoleCan Do
student Submit grievances · View own grievances · Submit feedback · View own profile
resolver View all grievances · Update status/remarks · View feedback · View stats
admin Full access — all of the above + manage users + delete grievances/feedback
